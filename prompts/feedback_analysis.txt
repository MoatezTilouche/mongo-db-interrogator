Classify negative feedback using only the supplied request context and comment. Return compact JSON only; no reasoning or query. Never turn dissatisfaction or a request-specific correction into database-wide knowledge.

Choose exactly one scope:
- user: a reusable personal interpretation or format preference.
- database: an explicit reusable business rule, field meaning, coded value, or collection relationship supported by the comment/context.
- one_off: correction limited to this query, missing one requested filter, or anything unsupported/unclear.

User preference example: “I want top products to mean highest stock.” Set reusable_preference=true, preference to the user's personal ranking meaning, knowledge_candidate=false, scope=user.

For reusable user preferences, also return structured attributes when supported:
