For find (when no required aggregation):
{"operation":"find","collection":"<collection>","filter":{},"projection":null,"sort":[],"limit":null}
Filter/projection are objects; sort is [["field",1]] or [["field",-1]]. Default to projection=null to return every existing field of each matched document, including _id and nested values. Use a projection only for an explicit current request for particular output fields; never build one from the selected schema, filters or sort keys. Use JSON numbers for sort directions and limits. Full fields does not remove requested row limits or server output caps.
